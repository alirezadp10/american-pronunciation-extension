# American Pronunciation Extension 🇺🇸🔊

A lightweight browser extension that helps users improve their **American English pronunciation**.  
The extension integrates with the browser to provide word/phrase pronunciation through the **Web Speech API** (Text-to-Speech) directly in the browser.

---

## ✨ Features

- 🔉 **American English Pronunciation** – hear words and sentences in a clear American accent.  
- 📑 **Context Menu Support** – right-click on any selected text and choose *“Pronounce in American English”*.  
- 🎛️ **Customizable Options** – adjust speech rate, pitch, and volume.  
- ⚡ **Lightweight** – no heavy dependencies; uses built-in browser APIs.  
- 🌐 **Offline Ready** (depending on system voices) – pronunciation works without an internet connection.  


## Load the Extension:

- Download the project.
- Go to `chrome://extensions/`.
- Enable "Developer mode".
- Click "Load unpacked" and select the directory containing your `manifest.json`, `background.js`, and `icons`.

## Set a Shortcut for the Extension:

- Go to `chrome://extensions/shortcuts` in your browser.
- Find your extension in the list.
- Click the pencil icon next to the command you want to set (e.g., "Activate the extension"), then press your desired key combination (e.g., `Alt+P` in Windows  or `Command+P` on Mac) to assign it.

## Test the Extension:

- Highlight a word on any webpage.
- Press `Alt+P` (or `Command+P` on Mac) — or use your custom shortcut if you’ve set one.
